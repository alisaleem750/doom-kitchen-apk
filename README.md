# A & S Doom Kitchen (Android)

Releases of the A & S Doom Kitchen Android app. This repository holds only the built APKs; the
source code is private.

**Install or update:** open this link in **Chrome** on your phone and install the downloaded file:

https://github.com/alisaleem750/doom-kitchen-apk/releases/latest/download/doom-kitchen.apk

Every build is signed with the same key, so a new version installs over the old one.
